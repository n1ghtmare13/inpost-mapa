# Mapa godzin granicznych InPost

Link do aplikacji: https://n1ghtmare13.github.io/inpost-mapa/

Interaktywna mapa prezentująca strefy oraz maksymalne godziny nadania przesyłek w usłudze InPost dla odbioru tego samego dnia.

Aplikacja zawiera wyszukiwarkę kodów pocztowych oraz aktualną bazę urządzeń Paczkomat i punktów PaczkoPunkt.

## Godziny graniczne

| Strefa | Maksymalna godzina nadania |
| :---: | :---: |
| A | do 16:00 |
| B | do 15:00 |
| C | do 14:00 |
| D | do 13:00 |

## Aktualizacja danych

Dane dotyczące stref oraz lokalizacji punktów są pobierane z oficjalnych, publicznych zestawień InPost. Aktualizacja bazy jest wykonywana automatycznie raz w tygodniu za pomocą GitHub Actions.

## Informacja prawna

Serwis ma charakter wyłącznie informacyjny. Znaki towarowe InPost, Paczkomat oraz PaczkoPunkt należą do Integer.pl SA / InPost Sp. z o.o.
